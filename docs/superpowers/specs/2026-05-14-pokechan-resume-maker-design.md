# ポケチャン履歴書メーカー — 設計ドキュメント

**作成日**: 2026-05-14
**ステータス**: 要件定義完了・実装プラン未作成

---

## 1. プロダクト概要

### 1.1 目的
ポケモンチャンピオンズ（以下「ポケチャン」）のプレイヤーが、自己紹介画像をブラウザ上で簡単に作成し、X (旧Twitter) へ「#ポケチャン履歴書」ハッシュタグ付きで投稿することで、新規フォロワー獲得と相互コミュニケーションを促進する Web ツール。

### 1.2 ターゲット
| 区分 | 層 | 配慮ポイント |
|---|---|---|
| 主軸 | エンジョイ・カジュアル層 | 戦績より「推し・好み・自己紹介」が主役 |
| サブ | ポケチャンからの新規参入層 | 用語ハードルを下げる、「初心者です」型ポストを支援 |
| 副 | 女性プレイヤー層 | デザインで「映え」「可愛さ」を意識した選択肢を用意 |
| 対象外 | 競技ガチ勢のレート自慢 | 戦績は任意項目に留める |
| 対象外 | コレクター勢 | ポケチャンは対戦特化ゲームのためそもそも非該当 |

### 1.3 成功指標
- **主目的**: X上で「#ポケチャン履歴書」を伴う投稿が一定数発生し、生成画像が拡散される
- **副目的**: 開発者（ユーザー本人）のポケチャン関連アプリ開発者としてのブランディング。今後も同領域でアプリを継続リリースする計画あり

### 1.4 既存ツールとの差別化（最強の売り）
**編集UX**。既存ポケモン履歴書ツールへの主な不満（編集が手間／テンプレ画像を自前で加工する必要）を解消する。

サブの売りとして「複数の洗練されたデザインテーマ」を提供。

## 2. 機能要件

### 2.1 入力項目（14フィールド）

#### 必須（5）

| # | フィールド | 入力形式 | 制約 |
|---|---|---|---|
| 1 | ハンドルネーム | テキスト | 1〜20文字 |
| 2 | アイコン画像 | ファイルアップロード | jpg/png、5MB以下、クライアント側で正方形クロップ |
| 3 | 推し（純粋推しポケモン） | ポケモン選択UI | 1〜3匹 |
| 4 | バトルでの推し | ポケモン選択UI | 1〜3匹 |
| 5 | 一言コメント／自己紹介 | テキストエリア | 30〜60文字推奨（上限80） |

#### 任意（9）

| # | フィールド | 入力形式 | 制約 |
|---|---|---|---|
| 6 | 推しの並び | ポケモン選択UI | 2〜3匹（「並び」用語のまま、ヘルプテキストで補足） |
| 7 | プレイ歴 | テキスト入力＋プリセット候補チップ | 例: 「ポケチャンから」「ポケモン歴◯年」。チップタップで自動入力、自由編集可 |
| 8 | 好きなルール | チェックボックス | シングル / ダブル の複数選択可 |
| 9 | 主戦場 | 単一選択 | ランクマッチ / フレンド戦 / 大会 / その他 |
| 10 | 好きなバトルスタイル | テキスト入力＋プリセット候補チップ | プリセット: 対面 / サイクル / 展開 / 推し活かす派。チップタップで自動入力、自由編集可 |
| 11 | 現在ランク | 階層選択（級 + 段階） | モンスターボール級〜チャンピオン級、各級に段階 |
| 12 | 配信／他SNSリンク | URL | YouTube、Twitch、Instagram等 |
| 13 | こんな人と繋がりたい！ | テキストエリア | 〜60文字程度 |
| 14 | 推しのポケモン活動者 | テキスト | 〜50文字、自由記述 |

#### ランク選択肢

```
モンスターボール級（Ⅳ → Ⅲ → Ⅱ → Ⅰ）
スーパーボール級（Ⅳ → Ⅲ → Ⅱ → Ⅰ）
ハイパーボール級（Ⅳ → Ⅲ → Ⅱ → Ⅰ）
マスターボール級（Ⅳ → Ⅲ → Ⅱ → Ⅰ）  ← ここから順位表示
チャンピオン級（上位300位）
```

### 2.2 ポケモン選択UI

- デフォルトは**ポケチャン内定ポケモン211件**から選択
- トグルで「全ポケモン1050件」に拡張可（将来のアップデート対応）
- インクリメンタル検索（カタカナ入力で絞り込み）
- 選択済みポケモンはチップで表示、×で削除
- 形態違い（例: ライチュウ（アローラ））は独立エントリとして扱う

データソース:
- `data/pokemon-pokechan.json` — 内定211件
- `data/pokemon-all.json` — 全1050件
- いずれもプロジェクト同梱の `ポケモンリスト（ポケチャン内定のみ）.txt` および `ポケモンリスト（全ポケモン）.txt` から生成

### 2.3 デザインテーマ

ローンチ時は **3テーマ** を提供（1テーマ追加検討中）:

| テーマID | 名称 | 雰囲気 | 主ターゲット |
|---|---|---|---|
| `official` | ゲーム公式風 | トレーナーカード調、上部赤バー、モンボ装飾 | 男女問わず／ポケチャンらしさ重視 |
| `retro` | レトロドット | GB初代の液晶緑、ドット風タイポ | 古参・男性層 |
| `starry` | 星空・月夜 | 紺＋月＋金/紫グラデ、エレガント | 大人女性層 |

各テーマ内に**カラーバリエ展開**を将来実装（例: official の赤/青/緑/紫、starry の紫/青/緑系）。

### 2.4 画面・UX

#### 画面構成（シングルページ）

```
+---------------------------------------+
| ヘッダー（タイトル / テーマ切替）        |
+---------------------------------------+
| [プレビュー]      | [入力フォーム]        |  ← PC: 左右2カラム
|  ライブ更新       |  全フィールド一覧     |
|                  |                      |
| [ダウンロード]   | [Xでシェア]          |
+---------------------------------------+
```

#### モバイル時

```
+---------------------------------------+
| ヘッダー / テーマ切替                  |
+---------------------------------------+
| [プレビュー（固定・縮小）]              | ← 画面上部に sticky
+---------------------------------------+
| [入力フォーム（スクロール可能）]        |
|                                       |
| [ダウンロード] [Xでシェア]              |
+---------------------------------------+
```

#### 入力フロー

1. 初回アクセス時にテーマ選択モーダル（スキップ可、デフォルトは `official`）
2. フォームに入力 → リアルタイムでプレビュー更新
3. テーマは右上のセレクタで随時切替可能
4. 入力途中の状態は `localStorage` に自動保存
5. 「ダウンロード」または「Xでシェア」で完成

### 2.5 画像出力仕様

| 項目 | 仕様 |
|---|---|
| アスペクト比 | 1:1 正方形 |
| 解像度 | 2160 × 2160 px（2倍解像度） |
| ファイル形式 | PNG（固定） |
| ダウンロード時のファイル名 | `pokechan-resume-{handle}-{YYYYMMDD-HHMMSS}.png`（handle未入力時は `anonymous`） |
| クレジット表記 | 画像右下に控えめなツールURL（例: `pokechan-resume.vercel.app`） |

### 2.6 共有導線

| プラットフォーム | 挙動 |
|---|---|
| モバイル | Web Share API を呼び出し、OS の共有シートで X 直接シェア（画像も添付） |
| PC | ① PNG ダウンロード → ② X 投稿画面を新タブで開く（`https://x.com/intent/tweet?text=...` で本文・ハッシュタグ事前埋め込み） |

#### 事前埋め込みテキスト

```
ポケチャン履歴書を作りました！

[ツールURL]
```

## 3. 技術設計

### 3.1 スタック

| レイヤ | 採用技術 | 理由 |
|---|---|---|
| フレームワーク | **Next.js (App Router) + TypeScript** | モダン、Vercelとの相性、開発者ブランディングにフィット |
| スタイリング | **Tailwind CSS** | テーマ別スタイルを variables で管理しやすい |

### 3.4 データモデル

```ts
// 入力フォームの完全な型
type ResumeForm = {
  // 必須
  handle: string;

  battleOshi: string[];         // 1-3

  playHistory: string;          // 自由記述

  battleground: 'ランクマッチ' | 'フレンド戦' | '大会' | 'その他' | null;

  rank: { tier: string; step: string | null } | null;

type AppState = {
  form: ResumeForm;
  themeId: ThemeId;
  pokemonListMode: 'pokechan' | 'all';  // 211 or 1050

```

### 3.5 データ保存・プライバシー

- **アカウント不要**
- **サーバーには何も保存しない**
- **ブラウザの `localStorage` に入力状態を自動保存**（次回アクセス時に復元）
- **アイコン画像はlocalStorageに保存しない**（容量上限・プライバシー観点）。再アクセス時は再アップロードが必要。代わりにユーザーがダウンロードした画像内に状態は永続化される
- テーマ切替時、入力データは保持される（store内のテーマIDのみ変更）
- ユーザーが明示的にクリアできる「リセット」ボタンを用意

### 3.6 法務・コンテンツ方針

| 項目 | 方針 |
|---|---|
| 公式ポケモン画像 | **使用しない**（ホストもしない、参照もしない） |
| 公式タイプアイコン | 使用しない |
| 公式フォント | 使用しない |
| ポケモン名 | テキストとして使用（名前自体は著作権対象外と一般に解されている） |
| ポケモン表示 | テキスト名 + 自作スタイルのピル装飾 |
| ユーザーアップロード画像 | 任意。「アップロード画像の著作権はユーザー自身に帰属し、その責任もユーザーが負う」旨をフッターに明記 |
| タイプ色バッジ | MVPでは未実装。将来 PokéAPI 等で型データ取得して拡張可能 |
| クレジット表記 | 画像右下に控えめなツール名/URL |

## 4. スコープ外（MVP）

以下は意図的にスコープ外。将来の拡張候補:

- 多言語対応（英語版等） — 日本ユーザー専用としてリリース
- アカウント機能、履歴書一覧、コミュニティ機能
- タイプ色バッジ（タイプ情報のデータ拡充が必要）
- 4つ目のデザインテーマ（追加検討中、ローンチ後追加可）
- 並びの相性チェック等のゲーム的サポート機能
- 各テーマのカラーバリエ（赤/青/緑等）— ローンチ後に追加
- 画像のテンプレ画像保存機能（X以外のSNS最適化）

## 5. オープン項目

ローンチ前に確定が必要な細部:

- ツール名（仮: 「ポケチャン履歴書メーカー」）
- ツールURL（Vercelの `*.vercel.app` ドメイン名）
- 各テーマの最終色味調整、背景模様
- ユーザーアップロード画像の責任表示文言
- 「並び」用語に対する説明ヘルプテキストの内容
- ハッシュタグの確定（`#ポケチャン履歴書` で確定だが、追加で `#ポケモンチャンピオンズ` 等を入れるか）
